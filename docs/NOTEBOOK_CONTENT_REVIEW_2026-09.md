→ 实训 → 错误恢复 → 易错点。**每个环节都在回答上一环节留下的问题**，而非并列堆砌。

各模块统一配有**学习弧 banner**（"第 N / 10 步" + 承接上一阶段 → 本章任务 → 下一步 + 大作业连接），
把独立章节串成单一主线项目（如 Pandas 全程围绕"电商履约异常追踪台"）。

## 1. 总体结论

结构层面：**优**。127 个 notebook 的 h2 小节编号 0 处跳号/重号；跨章"第 N 章"引用 0 处指向不存在章节；
每章均有场景/目标/核心概念/速查/示例/易错点/小结；公式块位置无回归（均在示例之后）。

内容层面：**中—**。存在一个**贯穿全课程的模板化缺陷**：`本章实训`、`错误恢复`、
`独立迁移练习` 三个环节的**正文是按模块复制的原型**，与所在章的实际主题脱节；
另有**前置知识断裂**（第 84/85 章）、**失效的编号引用**（26 处）等硬伤。

## 2. 核心发现

### 2.1【高】模板环节正文被按模块复制，与本章主题脱节

统计口径：对每章的 `本章实训` / `错误恢复` 环节，取标题后第一个正文单元格做 md5，

| Matplotlib | ch34–43 复用 ch33 | ch34–43 复用 ch33 | **专属（正常）** |

| 机器学习 | ch89–113 复用 ch87 | ch89–113 复用 ch87；ch114–119 复用 ch82 | 25 章复用 ch17 空模板 |

**同模块内"实训/错误恢复"标题也被复制**（标题声明本章主题，正文却是别章内容）：

- NumPy：ch18–21 标题均为"本章实训：axis 与布尔筛选"——但 ch19 讲形状变形、ch20 讲广播、ch21 讲统计抽样；
- Pandas：ch24–31 标题均为"本章实训：分组汇总与粒度"——但 ch26 讲数据质量、ch30 讲合并连接、ch31 讲窗口计算；
- Matplotlib：ch34–43 标题均为"本章实训：图表只改一个编码"；
- Seaborn：ch46–63 标题均为"本章实训：分组比较与不确定性"（18 章同题）；
- Plotly：ch66–81 标题均为"本章实训：交互图与信息层次"（16 章同题）；
- 机器学习：ch89–113 标题均为"本章实训：模型与基线比较"（25 章同题）。

**后果**：学员在 KMeans、PCA、SVM、箱线图、漏斗图等章节，标题承诺"本章专属实训"，
点开后拿到的是 `visits/discount → DummyRegressor vs LinearRegression`
或"客户-金额"清洗这类与本主题无关的原型练习。**实训环节的教学增量接近于零**。

具体越界最严重的两处：
- ch97（KMeans 聚类）的"本章实训"正文 = ch87 的**监督回归**练习（聚类章做回归，且用了本章未讲的模型）；
- ch107（Brier Score 校准）的"错误恢复"正文 = ch87 的**特征泄漏**处理（与本指标无关）。
