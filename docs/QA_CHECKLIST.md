# QA 验收清单

## 1. 内容完整性

- [ ] `notebooks/course` 包含 32 个课程 Notebook；
- [ ] `notebooks/extras` 包含 2 个补充 Notebook；
- [ ] 所有 Notebook 通过 nbformat 校验；
- [ ] 第一章不包含代码单元格；
- [ ] 课程 manifest 与磁盘文件一一对应；
- [ ] 中文文件名能在构建和部署后正常打开。

## 2. 应用外壳

- [ ] 课程目录使用 MUI X RichTreeView；
- [ ] 搜索支持标题、模块和标签；
- [ ] 当前章节、已完成章节和普通章节可区分；
- [ ] 侧栏折叠不改变 Notebook 内部宽度计算错误；
- [ ] 移动端 Drawer 可通过 Escape 和遮罩关闭；
- [ ] 数据查看器使用 MUI X Data Grid；
- [ ] 学习概览使用 MUI X Charts；
- [ ] Zustand 状态刷新后按规则恢复。

## 3. 技术边界

- [ ] React 不查询 iframe DOM；
- [ ] Tailwind 不包含覆盖 `.Mui*`、`.jp-*`、`.lm-*`、`.cm-*` 的规则；
- [ ] JupyterLite 主题由正式扩展注册；
- [ ] Runtime Bridge 校验 origin、source 和协议版本；
- [ ] Store 不保存 Notebook JSON、DOM 或内核对象；
- [ ] React Bits 只出现在文档规定的位置；
- [ ] 无未使用的必选技术依赖。

## 4. Notebook 视觉

- [ ] 画布为连续纸面，不是 Card 列表；
- [ ] Markdown 阅读态无黑底和代码框；
- [ ] Markdown 选中状态只使用左线和轻量反馈；
- [ ] 代码单元格默认、hover、focus、selected 状态稳定；
- [ ] hover 不改变单元格尺寸；
- [ ] 运行按钮固定在代码单元格左侧；
- [ ] 操作栏不会覆盖长代码；
- [ ] 折叠后仍显示摘要和状态；
- [ ] 插入控件不会常驻占用垂直空间。

## 5. Notebook 功能

- [ ] 打开所有 32 个正式 Notebook；
- [ ] 新增代码单元格；
- [ ] 新增 Markdown 单元格；
- [ ] 运行当前单元格；
- [ ] 运行全部；
- [ ] 中断执行；
- [ ] 重启内核；
- [ ] 保存工作副本；
- [ ] 刷新后恢复修改；
- [ ] 下载 `.ipynb`；
- [ ] 恢复课程原始版本；
- [ ] 命令面板可通过 Escape 和点击外部关闭；
- [ ] 同一时刻不存在多个重叠菜单。

## 6. Python 与数据分析

- [ ] Pyodide 首次加载有真实阶段反馈；
- [ ] NumPy 导入和数组运算成功；
- [ ] Pandas 导入和 DataFrame 输出成功；
- [ ] Matplotlib 图像可见且比例正确；
- [ ] Seaborn 图像可见且文字可读；
- [ ] Plotly 图表非空、可交互且响应容器宽度；

- [ ] 长文本输出不会撑破页面；
- [ ] 大表格在输出区域内部滚动。
