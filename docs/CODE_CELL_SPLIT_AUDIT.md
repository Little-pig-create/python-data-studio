## 二、典型反面案例

### 案例 A：`chapter-117 cell#37`（8 类功能 · 43 行 · 错误恢复格）

一个 cell 里依次做了：
```
导入 6 个库 → make_classification 造数据 → train_test_split 切分 → 训练模型
→ 预测概率 → 测试集上循环选阈值 → 打印 → 又切一次验证集 → 再训练
→ 验证集上循环选阈值 → 打印 → 成本敏感性循环 → 行动量检查
```

**初学者会遇到的问题**：
- 跑到一半报错，**不知道是哪一步出的错**（43 行 8 个阶段）
- 想单独复现"验证集选阈值"这一步，**做不到**（变量被前面的代码绑死）
- 想对比"事故做法 vs 正确做法"，两个阶段混在同一格，**视觉上分不开**

### 案例 B：`chapter-23 cell#21`（Pandas 9 章共用的准备格 · 41 行）

```
导入 → read_csv(含 dtype/parse_dates) → rename(8 列) → 计算 sales 列
→ np.where 生成 status 列 → 打印 3 行 → head()
```

其中 `rename(columns={...})` 一个调用就占 12 行（8 个列名各占一行）。
这是**Pandas 9 章逐字复用**的同一段代码（实测：9 章共用 41 行准备格）。

## 三、拆分规范（建议）

### 规范 1｜一个 cell 一个功能

| 功能 | 独立成 cell？ |
| --- | --- |
| **导入** | ✅ 与"首个功能"合并在首格（避免纯 import 空跑） |
| **读取/构造数据** | ✅ 独立 |
| **数据清洗/处理** | ✅ 独立（清洗步骤多时，每步一格） |
| **特征工程/切分** | ✅ 独立 |
| **训练** | ✅ 独立 |
| **预测/打分** | ✅ 独立 |
| **评估/指标** | ✅ 独立 |
| **绘图** | ✅ 独立（一图一格） |
| **打印摘要** | ✅ 可并入相关功能格，不单独成格 |

### 规范 2｜拆分的推荐模板（以 ML 为例）

```
cell 1  # 导入 + 准备数据
        import ...
        X, y = make_classification(...)

cell 2  # 切分训练/测试集
        X_train, X_test, y_train, y_test = train_test_split(...)

cell 3  # 训练模型
        model = LogisticRegression(...).fit(X_train, y_train)

cell 4  # 在测试集上打分
        test_proba = model.predict_proba(X_test)[:, 1]

cell 5  # 事故：在测试集上选阈值（错误做法）
        ...

cell 6  # 正确做法：切验证集
        Xtr, Xval, ytr, yval = train_test_split(X_train, ...)

cell 7  # 在验证集上选阈值
        ...

cell 8  # 敏感性分析
        ...
```

**收益**：每格可单独运行、单独复现；报错能立刻定位（"刚才那一格"）；
"错误做法 vs 正确做法"在视觉上自然分开——**这本身就是教学的一部分**。

### 规范 3｜每格首行加职责注释

```python
# 本格：在验证集上选择成本最优阈值（而不是测试集）
```

### 规范 4｜保留必要的"合" 

不是越碎越好。以下情况**允许合并**：
- 导入 + 第一个数据准备动作（避免 1 行 import 单独成格）
- "训练 + 打印训练耗时"这类强绑定动作
- 参考答案（capstone）的里程碑格：可按"里程碑"而非"功能"拆分，但**一个里程碑内部仍应分步**

## 十、实施进度（第 3 轮）—— 关键突破

### 10.1 新增「三重校验」，彻底解决拆分安全问题

上一轮拆分丢失语句（`X, y = data.data, data.target`）后，本轮实现了
**`verify_blocks()` 三重校验**（`.dsh-work/safe_split4.py`）：

| 校验 | 作用 |
| --- | --- |
| ① 每块 `ast.parse` | 保证无语法错误 |
| ② **拼接后与原文 AST 完全等价** | **保证没有任何语句被丢弃**（正是上轮漏掉的那行） |
| ③ 变量流检查 | 使用的名字必须已在本块或更早块定义 |

自检证明有效：
```
校验正确拆分： (True, 'ok')
校验丢失语句： (False, 'AST 不等价（有语句被丢弃或改变）')   ← 成功拦截上轮的事故类型
```
