## 1. 关键事实（本会话核对）

- **改动落点**：`notebooks/course/*.ipynb` 是 `.gitignore` 忽略的派生树；git 跟踪且应用加载的是

  **只改 notebooks 树无效；只改单元格、不动注册表，会被 `--check` / 构建拦下或重新注入。**

## 2. 审阅发现：三类问题

### 2.1 循序渐进问题：公式块位置固定且过早（主要问题）

math 块全部被插入在章节**前 4%–22%**（第 3–8 个 cell），即"本章场景/目标"之后、
对应知识点**尚未讲解**之前。例：

- 第 2 章（变量、数据类型与运算符，Python 第一课）：公式块在第 3 个 cell（4%），
  早于 2.1"变量的本质"。公式含 $\sum_{i=1}^{n}p_iq_i$、$\max(0,S-d)$ 与 $P=\max(0,S-d)$；
- 第 6/9 章（字典、循环）：用 $\mathbf{1}(c_i=g)$ 指示函数与 $\sum$ 描述"循环累加分组汇总"，
  而读者此时刚开始学字典/循环；
- 第 7 章（集合）：Jaccard $J(A,B)=\frac{|A\cap B|}{|A\cup B|}$ + 容斥推导，放在读者
  **还没写出第一行集合代码**的位置。

结论：数学块是"固定槽位注入"，不是"随知识点就位"，与循序渐进目标冲突。
处置方向：保留的公式应**移动到对应小节讲解之后**（或与"代码对应"紧邻），而不是章节开头；
被删除的公式直接移除。

### 2.2 不必要公式：以记号重复代码已表达的含义

以下主题用 LaTeX 把"代码一眼可读的运算"再写一遍，对初学者反而增加记号负担（按模块归类）：

- Python 基础：第 2 章"金额计算链"、第 6/9 章"分组汇总"（指示函数）、第 7 章 Jaccard（容斥）——
  建议整块删除或以一句话"代码即公式"替代；
- 可视化（Matplotlib/Seaborn/Plotly）中纯业务口径类：占比/份额（ch35/67/40/75/76）、
  漏斗转化率（ch77）、瀑布逐步守恒（ch78）、时间线 duration=end−start（ch79）、
  地图按率比较 rate=count/exposure×k（ch80）、气泡面积 ∝ 数值（ch69）——
  多为 $A_i/\sum$、$x_{end}-x_{start}$ 等平凡关系，删除整块推导、保留"口径一句话"即可；
- 跨模块重复：同一主题在 Matplotlib 与 Plotly（乃至 Seaborn）重复注册（趋势 Δ/增长率 ch34/66、
  差值与占比 ch35/67、Pearson ch36/56/68、直方图密度 ch37/53/71、箱线图 IQR ch38/49/72、
  面积堆叠 ch39/70、构成守恒 ch40/75/76、CI ch41/47/48/57、KDE ch50/54/73……）。
  后出现的章节建议只做"回顾一句话 + 图 API 差异"，不必再走一遍完整推导。

### 2.3 内容级 Bug（顺手修）

- 第 2 章 math 块 LaTeX 损坏：`a_1+cdots+a_n=sum_{i=1}^{n}a_i`（`\cdots`、`\sum` 缺反斜杠），
  KaTeX 会把 `cdots`/`sum` 渲染成斜体字母。若保留该块必须修复；
- 第 6/7/9 章存在**截断的 TODO 练习格**（紧随 math 块）：内容为
  `# TODO：请在下方完成 —— <!-- math-foundation:... 阅读方法：先跟着步骤理...`
  来自 `scripts/apply-content-fixes.mjs` 把 math 块误当任务提示拼接，属坏格，应清理。

## 6. 遗留观察（建议后续处理）

1. **同一推导被逐字复用 2–4 次**：如"均值的不确定性区间"出现在 ch41/47/48/57 四处、
   "Pearson 相关系数" ch36/56/68 三处、"核密度估计" ch50/54/73 三处（共 21 组）。
   这是脚本注释里"复用推导"的既定设计，但读者会重复读到同一段推导。
   建议后续把第二次及以后的出现压缩为**一段回顾（公式 + 一句口径提醒）**，而不是整段推导。
2. **文件名与 catalog 编号偏移**（catalog 第 76 章 → 文件 course-chapter-69.ipynb）：
   内容自洽（文件内 H1 与 catalog 标题一致），但会误导维护者，
   建议后续做一次文件名归一。
3. 可视化模块中"平凡算式 + 真实口径陷阱"的块（漏斗包含关系、瀑布对账、地图小分母、
   气泡面积 vs 半径）经复核**保留**：公式本身简单，但陷阱提示有教学价值，不宜按"平凡"删除。
