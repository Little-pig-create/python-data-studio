# 产品定义

## 1. 产品名称

暂定名称：Python Data Studio  
中文描述：Python 数据分析课程工作台

## 2. 产品目标

让初学者在一个浏览器页面中完成以下闭环：

1. 找到课程章节；
2. 阅读概念和示例；
3. 运行或修改代码；
4. 查看表格、图表和错误；
5. 保存学习过程；
6. 下载 Notebook 作为个人成果。

产品重点不是复制 Colab 或 JupyterLab 的全部功能，而是提供更清晰的课程结构、更稳定的 Notebook 运行环境和更适合教学的视觉层级。

## 3. 目标用户

### 主要用户

- 第一次系统学习 Python 的学生；
- 希望通过 Notebook 学习数据分析的非计算机专业用户；
- 需要 NumPy、Pandas、Matplotlib、Seaborn 和 Plotly 入门课程的学习者。

### 次要用户

- 需要演示课程的教师；
- 需要检查 Notebook 内容和执行状态的课程维护者。

## 4. 用户能力假设

- 会使用浏览器、文件和基本键盘操作；
- 不要求安装本地 Python；
- 不要求理解虚拟环境、包管理和数据库；
- 不假设用户了解 JupyterLab 的工作区概念。

## 5. 核心用户任务

| 任务 | 预期结果 |
|---|---|
| 选择章节 | 在当前页面打开对应 Notebook |
| 阅读课程 | Markdown 具有稳定的阅读排版 |
| 运行代码 | 明确显示排队、运行、成功或错误 |
| 修改代码 | 自动记录未保存状态 |
| 查看数据 | 可以查看 DataFrame、CSV 和图表输出 |
| 保存学习过程 | 工作副本保存在浏览器中 |
| 下载成果 | 导出标准 `.ipynb` 文件 |
| 恢复课程 | 可以恢复当前 Notebook 的原始版本 |
| 继续学习 | 返回时恢复最近章节和学习进度 |

## 6. 产品范围

### 首期包含

- 75 个正式课程 Notebook；
- 2 个补充练习 Notebook；
- 课程树、搜索和最近访问；
- JupyterLite + Pyodide 浏览器运行时；
- Notebook 编辑、执行、保存、下载和恢复；
- Python 运行状态和错误反馈；
- MUI X 数据查看器；
- 学习进度概览；
- 浅色主题；
- 桌面、平板和移动端布局；
- 无障碍和减少动画支持。

### 首期不包含

- 用户账号；
- 云同步；
- 数据库；
- 多人实时协作；
- GPU；
- 远程 Jupyter Server；
- 教师后台；
- 作业自动评分；
- 自定义插件市场；
- 完整 IDE 文件管理能力。

## 7. 内容范围

课程按七个模块组织：

1. Python 基础：第 1–10 章；
2. NumPy：第 11–15 章；
3. Pandas：第 16–24 章；
4. Matplotlib：第 25–35 章；
5. Seaborn：第 36–54 章；
6. Plotly：第 55–71 章；
7. 综合项目：第 72–75 章。

`00_课程环境初始化.ipynb` 作为运行环境准备内容，不计入正式章节进度。

## 8. 设计原则

### 内容优先

课程和 Notebook 内容始终拥有最高视觉优先级。导航和控制区应安静、紧凑、可预测。

### 运行状态明确

用户必须能判断 Python 是否正在加载、已就绪、正在运行或发生错误。

### 渐进披露

初学者首先看到阅读、运行和保存；高级设置、数据检查与重置放在二级界面中。

### 稳定胜过装饰

任何动效都不能改变单元格尺寸、遮挡代码或造成布局跳动。

### 原始内容可恢复

课程源文件保持不可变，用户编辑发生在浏览器工作副本中，并始终提供恢复入口。

## 9. 成功指标

首期以可验证的产品指标为准：

- 新用户能在 30 秒内打开第一章；
- 首次运行代码时能明确看到运行时加载进度；
- 所有 75 个正式 Notebook 均可打开；
- 代码章节可以运行并生成输出；
- 刷新页面后用户修改仍存在；
- 用户能下载标准 Notebook；
- 任意支持视口下不存在顶栏、菜单和单元格重叠；
- 第一章不出现代码单元格；
- 关键操作全部可通过键盘完成。
