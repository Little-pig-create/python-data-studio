# 课程内容发布操作手册

- **版本**：V1.0
- **日期**：2026-08-02
- **目标**：把课程文档、Notebook、数据集和静态发布目录作为一个可审计版本发布

## 1. 发布前冻结

1. 确认课程事实为 117 个课程章节：109 个连续教学章节 + 8 个独立模块大作业章节、8 个模块；
2. 确认章节正式作业和独立实训不在当前主路径；
3. 确认教学代码不使用 `assert` 自检；
4. 记录提交范围和变更影响；
5. 暂停在发布分支上直接修改 Notebook。

## 2. 内容和数据检查

1. 解析全部章节和大作业 Notebook JSON；
2. 检查方法说明与独立代码 Cell 配对；
3. 搜索旧作业标题、旧路径和旧模块数量；
4. 校验数据 Manifest、源文件、浏览器副本和 Notebook 路径；
5. 校验数据许可、来源和快照日期。

## 3. 运行检查

1. 重启内核；
2. 按顺序运行代表性章节和全部模块大作业；
3. 抽查第 1、11、16、25、36、55、72、76、109 章；
4. 检查代码输出、图表、错误恢复和结果解释；
5. 在浏览器版和桌面版分别记录差异。

## 4. 静态目录同步

1. 确认 `public/course/` 有 109 个连续教学章节 Notebook（第 10 章文件操作为普通章节）；
2. 确认 `public/course/module-capstones/` 有 8 个大作业 Notebook；
3. 同步到 `dist/course/`；
4. 比较文件名、字节大小或哈希；
5. 检查 `catalog.json` 中的路径可达；
6. 确认数据副本也已同步。

## 5. 页面和无障碍检查

按 `QA_CHECKLIST.md` 检查桌面、平板和手机视口；至少抽查课程树、模块大作业入口、Notebook 输出、数据查看器、错误状态、键盘操作和减少动画模式。

## 6. 发布记录

发布记录必须包含：版本号、日期、内容范围、数据快照、Notebook 数量、构建命令、测试结果、已知风险、回滚方式和批准人。若静态目录未同步或冷启动失败，状态只能标记为“候选版”，不能标记为“已发布”。

## 7. 回滚

回滚必须同时回滚课程清单、Notebook、数据 Manifest、静态数据副本和文档版本记录。不能只回滚页面而保留不兼容的数据或 Notebook。


## 文件操作专题（Python 基础）

Python 基础模块第 10 章是普通教学章节“文件操作专题：读取、写入与目录管理”，主线使用 `os`、`open`、`csv`、`json`，内部目录与其他章节一致。日期与时间专题目前仅为设计方案，若未来新增，必须先更新目录和编号，再执行发布验收。
