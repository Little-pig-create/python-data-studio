## 项目概述

**Python Data Studio** - 浏览器端 Python 基础与数据分析课程工作台

这是一个基于 React 和 JupyterLite 的在线 Python 数据分析学习平台。React 外壳负责课程目录、进度和导航，JupyterLite 负责 Notebook 编辑与 Pyodide 运行时。

## 技术栈

### 前端框架
- **React + Vite + JavaScript** - 主框架
- **Tailwind CSS** - 样式系统
- **MUI** - UI组件库
  - MUI Core
  - MUI X Tree View
  - Data Grid
  - Charts
- **Zustand** - 状态管理

### Python运行环境
- **JupyterLite 0.8** - 浏览器端Jupyter环境
- **Pyodide kernel** - WebAssembly Python运行时

### JupyterLab扩展
- `jupyterlite-course-bridge` - Runtime Bridge通信
- `jupyterlite-course-theme` - 课程主题

## 开发指南

### 安装依赖

```powershell
npm install
.\.venv\Scripts\python.exe -m pip install -r runtime\requirements.txt
```

### 构建运行时

```powershell
npm run build:runtime
```

该命令会：
1. 编译 JupyterLab 扩展
2. 打包 `notebooks/course` 和 `notebooks/extras` 到 JupyterLite
3. 保留目录层级，避免同名 Notebook 覆盖

### 开发模式

```powershell
npm run dev -- --port 8766
```

访问: `http://127.0.0.1:8766/course/chapter-1`

### 生产构建

```powershell
npm run build
```

输出到 `dist/` 目录

## 特性说明

### 多语言支持
- Notebook 界面使用 JupyterLab 官方简体中文语言包
- 不通过前端脚本替换英文文案

### 架构特点
- Notebook 内部不由 React 查询或覆盖 DOM
- 主题通过 JupyterLab 正式主题扩展加载
- 运行、保存、内核和选中状态通过 `postMessage` 协议传回外壳
- React 外壳和 JupyterLite 通过同源 Runtime Bridge 通信
