### 3.2 新增小节的**内容设计**（拟写入的文案）

#### 新增 1：`## 38.2 数据结构`

> **密度基准**：模块内同类小节极简——ch37「一维连续数值样本；分组比较时各组应有足够样本量。」
> 仅 **24 字 / 1 行**。因此本小节的**主体也应是一句话**，只用要点补充箱线图特有的注意项。

```markdown
## 38.2 数据结构

一个或多个数值样本；分组比较时各组样本量应大致相当。

- 多样本一次传入：`ax.boxplot([group_a, group_b, group_c])`；
- 箱线图**不显示样本量 n**，组间样本量悬殊时中位数差异容易被误读；
- 缺失值需先剔除（`np.isnan` 过滤），否则四分位数统计会被拉偏。
```

**为什么这样写**：首句与 ch37 同款句式、同款密度（一句话说明数据结构 + 分组条件）；
其后 3 个要点只补箱线图**特有**的两点（不显示 n、缺失值影响四分位数），不与后文重复。

#### 新增 2：`## 38.3 本章练习任务`

> **密度基准**：ch37 为 **135 字 / 5 行**，格式统一为"运行基础图表后，完成以下任务：
> 1. 改某参数 A，观察影响 X / 2. 加参数 B，对比 Y / 3. 改 C，说明 Z 的作用"。

```markdown
## 38.3 本章练习任务

运行基础图表后，完成以下任务：

1. 把 `whis` 从默认的 1.5 改为 3.0，观察须的长度与须外点数量的变化
2. 添加 `showmeans=True` 参数，对比均值点与中位数线的位置差异，说明哪些组偏态明显
3. 把 `vert` 改为 `False` 画出水平箱线图，说明类别标签较长时这种方向更好读的原因
```

**为什么这样写**：
- 任务 1 对应本章「错误恢复」的主题（"把须外点当错误数据"）——让学生亲手看到 `whis` 的作用；
- 任务 2 对应本章「易错点」第一条（"只看中位数忽略离散程度"）——用均值/中位数位置差感受偏态；
- 任务 3 是箱线图的常用变体（`vert=False`），与"参数说明"小节呼应。
