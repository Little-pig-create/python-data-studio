# 信息架构

## 1. 总体结构

产品只有一个主要工作空间，不创建营销落地页。

```text
Python Data Studio
├─ 课程工作区
│  ├─ 课程目录
│  ├─ Notebook
│  ├─ Notebook 内部目录
│  ├─ 数据查看器
│  └─ 运行状态
├─ 学习概览
├─ 补充练习
└─ 设置
```

默认打开：

1. 若存在最近章节，恢复最近章节；
2. 否则打开第一章；
3. 首次需要运行代码时再加载 Pyodide；
4. 第一章不主动加载 Python 内核。

## 2. 路由设计

| 路由 | 用途 |
|---|---|
| `/course/:chapterId` | 打开章节 Notebook；模块末章中的大作业入口沿用章节上下文 |
| `/practice` | 课堂自检与补充材料入口（不作为章节正式作业） |
| `/training` | 历史实训兼容入口；当前课程不作为主路径 |
| `/progress` | 学习进度与模块概览 |
| `/settings` | 主题、字体和编辑器偏好 |

路由只表达用户可分享和恢复的应用状态。单元格选中状态、滚动位置和菜单开关不进入 URL。

## 3. 课程清单

构建时生成只读 `course-manifest.json`：

```text
id
order
title
module
notebookPath
kind
estimatedMinutes
hasCode
prerequisites
tags
```

`kind` 允许以下值：

- `setup`
- `lesson`
- `project`
- `capstone`（模块大作业资源，当前入口由模块末章关联）
- `extra`

## 4. 桌面布局

```text
┌──────────────────────┬──────────────────────────────────────────────┐
│ 课程工作台           │ JupyterLite Notebook                        │
│ 304 px               │ 剩余全部宽度                                │
│                      │                                              │
│ 品牌与进度           │ Notebook 标题与保存状态                      │
│ 课程搜索             │ 原生工具栏                                   │
│ MUI X RichTreeView   │ Notebook 画布                                │
│                      │                                              │
│ 底部面板切换         │                                              │
│ 运行时状态           │                                              │
└──────────────────────┴──────────────────────────────────────────────┘
```

桌面断点：

- `>= 1280px`：完整侧栏，宽度 `304px`；
- `1024–1279px`：紧凑侧栏，宽度 `264px`；
- `768–1023px`：图标轨道 `72px`，目录通过 Drawer 展开；
- `< 768px`：Notebook 全宽，目录为临时 Drawer。

## 5. 左侧工作台

从上到下分为五区：

1. 品牌和课程总进度；
2. 搜索；
3. 课程树；
4. 目录、数据、课程三个视图入口；
5. Python 运行状态。

课程树使用 MUI X RichTreeView。八个模块按顺序显示，模块大作业作为模块末章的关联入口；课堂自检和补充材料单独分区，不混入 Notebook 内部标题目录。

## 6. Notebook 区域

Notebook 区域从自己的标题栏开始完全属于 JupyterLite。React 外壳不在其上方重复放置运行、保存和下载按钮。

Notebook 区域内部层级：

```text
标题与保存状态
原生菜单和单行工具栏
Notebook 滚动画布
单元格
输出
状态栏（按需）
```

## 7. 辅助面板

### Notebook 目录

展示当前 Notebook 的 H1–H3 标题。点击后由 Runtime Bridge 请求 JupyterLite 滚动到目标标题。

### 数据查看器

使用 MUI X Data Grid 展示用户主动导出的表格数据。该面板不拦截或替换 Notebook 原生输出。

### 学习概览

展示八个模块完成率、模块大作业状态、最近章节和 Notebook 执行记录。图表使用 MUI X Charts，避免自定义绘图组件。

## 8. 移动端

- 顶部仅保留目录按钮、Notebook 名称和运行状态；
- 课程目录使用全高 MUI Drawer；
- 工具栏文字按优先级隐藏，保留图标和 Tooltip；
- Notebook 工具栏过窄时横向滚动，不换行；
- 数据查看器以全屏 Dialog 打开；
- 最小点击区域为 `44px × 44px`；
- 不使用依赖 hover 的唯一操作入口。

## 9. 空状态与异常状态

| 状态 | 页面表现 |
|---|---|
| 尚未载入 Notebook | 显示课程欢迎与继续学习入口 |
| Notebook 加载中 | 稳定尺寸骨架，不改变整体布局 |
| Python 首次加载 | 显示阶段进度和预计用途 |
| 运行时错误 | 提供重试、下载 Notebook 和错误详情 |
| Notebook 不存在 | 返回课程目录，不保留空白 iframe |
| 本地存储不可用 | 提醒用户及时下载，不承诺自动保存 |
| 离线且资源未缓存 | 明确说明需要联网完成首次加载 |
