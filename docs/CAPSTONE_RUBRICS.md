# 模块大作业评分量规

- **版本**：V1.0
- **日期**：2026-08-02
- **适用范围**：Python 基础、NumPy、Pandas、Matplotlib、Seaborn、Plotly、综合项目、机器学习八个模块

## 1. 统一评分结构

| 维度 | 权重 | 通过证据 |
|---|---:|---|
| 问题定义 | 15% | 说明任务、对象、输入、输出和成功标准 |
| 数据与可复现性 | 20% | 来源、许可、本地路径、字段说明、随机种子和冷启动可运行 |
| 方法正确性 | 25% | 方法选择合理，代码能运行，关键结果无明显逻辑错误 |
| 结果解释 | 20% | 有标签输出、图表说明、结论和限制，不只贴结果 |
| Notebook 结构与表达 | 10% | Cell 独立、顺序递进、Markdown 清楚、错误可恢复 |
| 反思与拓展 | 10% | 至少改变一个参数或条件并比较结果 |

总分 60 分及以上且“方法正确性”“数据与可复现性”均不低于该项满分的 60%，视为达到模块通过线。教师可以根据课程安排调整总分，但不得删除数据来源和结果解释要求。

## 2. 分级标准

- **优秀（90–100）**：流程完整，解释有证据，能主动讨论限制并完成有意义拓展；
- **良好（75–89）**：主流程正确，存在少量表达或边界遗漏，但不影响复现；
- **合格（60–74）**：完成必做范围，能运行并解释主要结果；
- **需返工（0–59）**：关键 Cell 无法运行、数据来源不明、存在明显泄漏或没有结果解释。

## 3. 八个模块的必做重点

| 模块 | 必做重点 | 推荐公开数据 |
|---|---|---|
| Python 基础 | 类型、字符串、容器、条件循环、函数、文件和异常路径 | 本地 CSV 小样本或课程自带文本数据 |
| NumPy | 数组创建、索引切片、广播、统计和形状变化 | Iris 或 Wine 数值特征 |
| Pandas | 读取、清洗、筛选、分组、合并和透视 | Iris、Wine 或公开 CSV |
| Matplotlib | 图表选择、坐标轴、标注、子图和结论 | Diabetes 或时间序列快照 |
| Seaborn | 分布、分类比较、相关关系和统计图形 | Iris、Wine、Breast Cancer |
| Plotly | 交互图表、筛选、悬停信息和可读性 | 多字段公开表格 |
| 综合项目 | 从问题定义到报告的完整分析流程 | 任选已登记本地公开数据 |
| 机器学习 | 基线、切分、预处理、训练、评估、解释和限制 | Iris、Wine、Diabetes、Breast Cancer |

## 4. 教师评语模板

- **做得好的地方**：指出一个具体的代码、图表或解释证据；
- **最重要的改进**：只指出一个优先级最高的问题；
- **复现检查**：说明是否从重启内核后完整运行；
- **下一步挑战**：给出一个改变参数、数据或方法的拓展问题。

评分不应只写“正确/不正确”，应让学生知道如何修订 Notebook。
