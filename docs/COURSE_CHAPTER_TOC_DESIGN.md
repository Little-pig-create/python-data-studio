# 各模块「章节内部目录」设计方案（模块专属版）

> 状态：**设计稿，未实施**（本轮未改动任何 notebook）
> 修正说明：前一版设计"四套通用章型 + 统一骨架"**过度统一**了。
> 实测发现各模块有**真正独有的环节**，强行拉平会丢掉模块特色。本版改为**按模块各设计一套目录**。

---

## 一、为什么不能统一：各模块的"独有环节"实证

| 模块 | 独有环节（其它模块几乎没有） | 覆盖率 |
| --- | --- | --- |
| **Python 基础** | 拓展作业（必做/选做/**下章预习**） | 14/16 |
| **NumPy** | 核心操作独立示例（每个方法一格） | 5/6 |
| **Pandas** | **公开大型数据实战**（UCI 20 万行） | 9/10 |
| **可视化三模块** | 数据结构 · 本章练习任务 · 基础图表 · 进阶变体 · 参数说明 · 结果解读 | 各 ~95% |
| **综合项目** | **数据字典 · 质量检查清单 · 项目任务 · 项目交付物 · 阶段检查点 · 最低完成标准 · 提升任务 · 结论与表达 · 项目验收清单** | 各 80% |
| **机器学习** | **建模流程提醒** | 29/34 |

结论：**这些环节是模块的教学特色，必须保留**。统一骨架会切掉它们。

---

## 二、各模块的定位与目录设计

### 模块 1｜Python 基础（16 章）——**语言语法教学**

**定位**：从零学语言 → 章章有练习 → 教会"怎么自己往下学"。
**特色**：唯一带「拓展作业 + 下章预习」的模块（因为要带初学者往前走）。

```
1. 本章场景
2. 本章目标
3. 知识点讲解          （本节内用 ### 分 3–6 个知识点，不占环节号）
4. 工具速查            方法地图表（模块内命名，与其它模块的"速查"同位）
5. 示例与输出解读      代码 + 逐行解读
6. 本章实训            3 个实验
7. 易错点提醒          3–5 条
8. 练习与作业          基础 / 提高 / 挑战
9. 小结                知识要点回顾 + 自测清单
10. 拓展作业           必做 / 选做 / 下章预习   ★模块特色
```

**核实结论**：Python 15 章**都已含「工具速查」**（先前误判为缺失，实为我的环节名正则只匹配了
"方法分类速查"）。
→ **本模块无需改动**。

---

### 模块 2｜NumPy（6 章）——**数组运算基础**

**定位**：建立"整批数据一起算"的思维；方法少而精。
**特色**：「核心操作独立示例」——每个 ndarray 方法一个独立可运行格子（初学者友好）。

```
1. 本章场景
2. 本章目标
3. 核心概念            三属性口诀（shape/ndim/dtype）
4. 方法分类速查
5. 示例 1 / 2 / 3      每例 = 背景引入 + 讲解 + 口诀 + 代码
6. 核心操作独立示例     每个方法一格，自带最小输入  ★模块特色
7. 独立迁移练习
8. 本章实训
9. 错误恢复：xxx 怎么办
10. 易错点提醒
11. 练习与作业
12. 练习路径           完成标准 / 分级提示
13. 小结               你已经掌握 / 验收标准 / 需要注意 / 完成检查 / 排错顺序
```

**现状**：已符合（12 环），**无需改动**。

### 模块 3｜Pandas（10 章）——**表格数据处理**

**定位**：从"能读写表"到"能回答业务问题"。
**特色**：唯一有「公开大型数据实战」——用 UCI Online Retail 20 万行真实数据按本章主题做一次实战。
这是全课程最亮眼的设计之一，**必须强化而非削弱**。

```
1. 本章场景
2. 本章目标
3. 核心概念
4. 方法分类速查
5. 示例 1 / 2 / 3
6. 核心操作独立示例
7. 公开大型数据实战      ★模块特色（20 万行真实数据）
8. 独立迁移练习
9. 本章实训
10. 错误恢复
11. 易错点提醒
12. 练习与作业
13. 练习路径
14. 小结
```

**现状**：已符合（13 环），**无需改动**。

### 模块 4–6｜Matplotlib / Seaborn / Plotly（47 章）——**图表教学**

**定位**：同一套"读图方法论"贯穿三种工具 ——
`数据结构 → 画基础图 → 加变体 → 调参数 → 读出结论`。
**特色**：环节最多（17 环）是**合理的**，因为"一种图表"确实需要"结构/画法/参数/解读"四个维度。

```
1. 本章场景
2. 本章目标
3. 适用场景            这种图回答什么问题、什么时候不该用   ← 模块内统一用"适用场景"
4. 数据结构            需要什么样的表（长表/几列数值/几列分类）
5. 本章练习任务        带着问题看图
6. 图表与参数速查      图表地图表
7. 准备可复现数据      统一数据 + 数学推导块
8. 基础图表            最小可用图 + 输出解读
9. 进阶变体            分组/布局/注释/交互
10. 参数说明           关键参数逐个解释
11. 结果解读           这张图读出了什么、还有什么读不出
12. 本章实训
13. 错误恢复
14. 易错点提醒
15. 练习与作业
16. 独立迁移练习       换个图的表达方式
17. 小结               你已经掌握 / 关键参数 / 需要注意 / 完成检查 / 下一步推荐
```

**现状**：47 章中 **45 章完全符合**；仅 **matplotlib ch38 / ch40 缺「数据结构」「本章练习任务」**（已核实）。
→ **建议**：仅补这 2 章的 2 个环节；**不做压缩**（前一版设计要删「练习任务」是错的，
它与"实训"不同：前者是"看图前的提问"，后者是"动手做"）。

### 模块 7｜综合项目（5 章）——**端到端项目训练**

**定位**：把前面所有技能串起来做完整分析，并**交付**。
**特色**：唯一有「交付物 / 检查点 / 完成标准 / 结论与表达 / 验收清单」的模块 ——
因为项目教学的重点是**交付质量**，不是知识点。

```
1. 本章场景
2. 本章目标
3. 数据字典            ★项目必须交代字段  ← 建议综合项目 4 章都补（ML 项目已有）
4. 数据质量检查清单      ★先审计再动手      ← 同上
5. 项目任务            任务清单
6. 项目阶段速查        每阶段做什么、留什么证据
7. 项目交付物          交付什么
8. 阶段检查点          中途自检
9. 最低完成标准        及格线
10. 提升任务           做得更好
11. 分析链路（3–5 节）  本项目的核心分析步骤
12. 本章实训
13. 错误恢复
14. 易错点提醒
15. 结论与表达         结论 + 限制与假设
16. 项目验收清单        逐项自检表
17. 小结               你已经完成 / 质量提醒 / 交付检查 / 后续迭代建议
```

**现状**：已符合（16 环），**仅需补「数据字典 / 质量清单」**（现 80%）。

### 模块 8｜机器学习（34 章）——**建模方法论**

**定位**：不是"学十个算法"，而是学**一套可信的建模纪律**
（定义问题 → 基线 → 防泄漏 → 评估 → 解释 → 上线）。
**特色**：「建模流程提醒」环节（29/34）—— 反复强调口径、泄漏、评估纪律。

```
1. 本章场景
2. 本章目标
3. 核心概念            算法直觉 + 直观类比
4. 方法分类速查
5. 示例 1：数据与问题定义
6. 示例 2：模型、公式与诊断
7. 建模流程提醒         ★模块特色（口径 / 泄漏 / 评估）
8. 独立迁移练习
9. 本章实训
10. 错误恢复
11. 易错点提醒
12. 练习与作业
13. 练习路径
14. 小结
```

**现状**：已符合（11 环）。
其中 4 章（ch116–119）是**项目型**（数据字典→…→验收清单），与其余 29 章不同 ——
这是**合理差异**（它们是 ML 模块内的项目），保留。

**核实结论**：全部 29 个知识章的「独立迁移练习」**都在「本章实训」之前**，顺序一致，
**无需改动**（先前"ch111 顺序异常"是我的环节匹配正则的误报）。

### 附｜「方法地图」环节的模块化命名（现状，建议保留）

实测该环节用了 **5 种模块适配的标题**，出现在约 112 章：

| 标题 | 章数 | 模块 |
| --- | --- | --- |
| `方法分类速查` | 48 | NumPy / Pandas / 机器学习 |
| `图表与参数速查` | 47 | Matplotlib / Seaborn / Plotly |
| `工具速查` | 13 | Python 基础 |
| `项目阶段速查` | 4 | 项目章 |

**建议保留这种差异**：图表章需要"图表+参数"，Python 章是"工具"，项目章是"阶段"——
名称贴合模块语义，比强行统一更好。
