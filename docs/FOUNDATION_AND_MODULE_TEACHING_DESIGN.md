- **版本**：V1.1
- **日期**：2026-08-02
- **状态**：设计方案，仅用于指导后续 Notebook 改造
- **本轮边界**：本轮只记录教学设计，不修改代码、Notebook、课程目录、数据文件或发布目录
- **适用范围**：Python 基础前 11 章、NumPy、Pandas、Matplotlib、Seaborn、Plotly、综合项目、机器学习和模块大作业

## 1. 设计背景与核心问题

当前课程已经建立了模块划分、独立模块大作业、方法独立 Cell 和 `print()` 结果输出等基本规范，但前置章节仍需要进一步补齐基础概念，后续模块也需要使用同一套“讲清楚、练完整、可迁移”的教学方式。

本方案重点解决以下问题：

1. 初学者在前几章缺少计算机、程序、变量、类型、表达式和执行顺序的完整基础；
2. 方法和函数虽然已经出现，但部分章节仍需要增加参数、返回值、原对象变化、副作用和边界情况说明；
3. 文件操作需要同时覆盖 `os`、`open`、CSV、JSON 和错误处理；
4. 时间处理能力应该作为跨模块基础能力加入课程，而不是只在 Pandas 章节零散出现；
5. NumPy 及以后模块也应沿用独立方法说明、独立示例、结果解释和错误恢复的规范；
6. 每个模块需要形成从概念到综合项目的连续学习路径，而不是知识点集合。

## 2. 全课程统一教学原则

### 2.1 每章都回答四个问题

每个章节 Notebook 至少要让学生能够回答：

1. **输入是什么**：变量、文本、数组、表格、文件或模型输入；
2. **处理做了什么**：调用了什么函数、使用了什么参数、进行了什么变换；
3. **结果是什么**：打印了什么、表格或图形显示了什么；
4. **结果意味着什么**：结论的适用范围、限制和下一步是什么。

### 2.2 每个重要方法使用独立 Cell

每个核心方法或函数必须采用以下最小结构：

```text
Markdown Cell：作用、调用形式、参数、返回值、副作用、边界情况
Code Cell：最小可运行示例
Markdown Cell：解释输出和常见误区
Code Cell：真实场景示例（复杂方法可选）
```

不能把多个不相关的方法集中在一个代码 Cell 中，也不能只用一个实例代替方法说明。

### 2.3 不使用 `assert` 作为教学自检

课程统一使用：

- `print()` 输出检查结果；
- `if/else` 输出清晰提示；
- `try/except` 处理可预期错误；
- 表格、摘要和图形呈现检查结果。

自检要说明“检查了什么、结果是什么、发现问题后怎么处理”，而不是只得到一个真假值。

### 2.4 不强制所有章节使用公开数据

数据策略按教学目的选择：

| 类型 | 适用场景 |
|---|---|
| 课程内生成的模拟数据 | 语法、NumPy、Matplotlib、实验和算法概念 |
| 课程本地快照 | Pandas、Seaborn、Plotly、机器学习和综合项目 |
| 合规公开数据 | 综合项目拓展或真实业务案例 |
| 用户自建小数据 | 文件操作、函数、数据质量和项目设计 |

使用公开数据时必须写明来源、快照、字段、许可、粒度和限制；不使用公开数据时也必须说明数据是如何生成的、随机种子是什么、生成逻辑有哪些假设。

## 5. 时间与日期专题设计：Python 普通章节 + 跨模块基础能力

时间内容不建议只作为 Pandas 的一个小节。推荐先设计为 Python 基础模块的普通教学章节（规划第 12 章），再在 Pandas、可视化、综合项目和机器学习中按任务需要重复使用。当前仅写入设计文档，不新增目录项、不修改现有章节编号，也不修改 Notebook。

### 5.0 规划章节的定位与单元格顺序

- **章节性质**：普通教学章节，不是实训模块，不是章节作业，也不是模块大作业；
- **建议位置**：异常处理之后、Python 基础模块大作业之前；

- `zoneinfo.ZoneInfo`（进阶）。

建议在文档和 Notebook 中为每个方法固定填写以下字段：

| 方法/函数 | 必须讲清楚的内容 | 至少两个示例 | 必须覆盖的边界 |
|---|---|---|---|
| `date()` / `time()` / `datetime()` | 构造参数、返回对象、对象是否可变 | 构造一个正常值；修改一个参数后比较结果 | 月日越界、小时/分钟范围、微秒 |
| `today()` / `now()` | 获取的时钟来源、返回类型 | 日期显示；带时间显示 | 运行时间变化、不要把示例输出当固定答案 |
| `timedelta()` | 天、秒、微秒参数和加减方向 | 预计日期；计算两个时间间隔 | 负间隔、跨月、跨年 |
| `strptime()` | 输入字符串、格式串、返回 datetime | 两种格式解析；批量解析一列 | 空字符串、非法日期、格式不匹配 |
| `strftime()` | 格式符、返回字符串、显示用途 | 中文报告格式；文件名格式 | `%m` 与 `%M`、时区显示 |
| `combine()` | date 与 time 的组合关系 | 预约时间；日志时间拼接 | 缺失时间、时区信息是否保留 |
| `timestamp()` | Unix 时间戳、时区影响 | 转换为秒；再转回日期时间 | naive datetime 的解释差异 |
| `ZoneInfo` | 时区对象、夏令时和 aware datetime | 北京时间与 UTC；跨时区比较 | 未安装时区数据、混合 naive/aware |

每个函数都需要说明：

- 输入格式；
- 返回对象类型；
- 格式字符串含义；
- 时区是否包含；
- 无效日期如何报错；
- 是否修改原对象。
