# Notebook 主题规范

## 1. 实现方式

Notebook 视觉由独立包 `jupyterlite-course-theme` 实现。

该包：

- 注册正式 JupyterLab 主题；
- 映射共享设计令牌到 `--jp-*` 变量；
- 为 Notebook、Cell、CodeMirror 和 Output 提供主题样式；
- 不依赖外层 React；
- 不向全局页面注入 Tailwind；
- 不通过运行时脚本反复修改内联样式。

主题扩展可以使用 JupyterLab 的稳定语义类和主题变量，但不得依赖构建生成的 ID、随机 class 或 `nth-child`。

## 2. 视觉目标

Notebook 应呈现为连续、安静、专业的技术工作纸：

- 阅读内容无卡片化边框；
- 代码区域与阅读区域有清晰但克制的差异；
- 运行状态靠近单元格；
- 输出属于对应代码单元格；
- 选中状态使用 Colab 风格的完整蓝色轮廓；
- 动态内容不引发布局跳动。

## 3. Notebook 画布

| 属性 | 规范 |
|---|---|
| 工作区背景 | `surface` |
| Notebook 背景 | `surface` |
| 内容最大宽度 | 不限制，左对齐铺满工作区 |
| 桌面水平间距 | 左侧外边距 `4px` + 编号列 `40px`，右侧 `12px` |
| 移动端水平间距 | 左侧外边距 `2px` + 编号列 `40px`，右侧 `8px` |
| 顶部留白 | `18px` |
| 底部留白 | `96px` |
| 代码单元格间距 | 上 `8px`、下 `12px` |

画布不得被放进浮动 Card。Notebook 本身是一个连续页面。

## 4. 标题栏与工具栏

### 标题栏

单行展示：

- Notebook 文件名；
- 保存状态；
- Python 运行状态。

文件名过长时截断并提供 Tooltip。保存状态只使用以下文案：

- 已保存；
- 有未保存更改；
- 正在保存；
- 保存失败。

### 工具栏

- 固定高度 `40px`；
- 背景使用 `#f0f4f9`，整体为胶囊形命令条；
- 所有控件禁止换行；
- 桌面显示图标和必要文字；
- 窄屏优先隐藏文字；
- 极窄屏允许工具栏内部横向滚动；
- 不允许工具栏高度随内容增加。

主要动作：

- 运行当前单元格；
- 运行全部；
- 停止；
- 保存；
- 下载；
- 添加代码单元格；
- 添加 Markdown 单元格。

工具栏使用 JupyterLite 原生命令和扩展，不由外层 React 复制。

## 5. Markdown 单元格

### 阅读状态

- 无边框；
- 无背景色；
- 无阴影；
- 隐藏 JupyterLab 原生 Collapser 和 InputPrompt；
- 单元格左边缘与代码框对齐，正文从框内 `8px` 开始；
- 内容宽度不超过 `1000px`；
- 正文 `16px / 25.6px`；
- 标题与正文间距按语义层级确定；
- 表格、引用、列表和代码块必须有稳定间距。

### 选中状态

- 使用 `2px #0b57d0` 完整轮廓；
- 不增加左侧色条、蓝色填充或焦点阴影；
- 操作按钮在右上角出现；
- 焦点状态必须符合键盘可见性要求。

### 编辑状态

- 编辑器背景使用 `code-surface`；
- Markdown 源码与渲染结果切换不改变单元格外部宽度；
- `Escape` 返回命令模式；
- `Shift+Enter` 渲染并移动到下一单元格。

### 第一章

第一章只包含 Markdown：

- 不显示无意义的运行时引导；
- 不主动加载 Pyodide；
- 不展示代码运行按钮；
- 默认进入阅读状态。

## 6. 代码单元格

### 固定结构

```text
CodeCell
├─ ExecutionCount (框外左侧)
├─ InputFrame
│  ├─ RunGutter (40px)
│  └─ Editor
├─ InputOutputDivider
└─ OutputFrame
   ├─ OutputGutter (40px)
   └─ OutputArea
```

### 默认状态

| 属性 | 规范 |
|---|---|
| 背景 | `code-surface` |
| 默认轮廓 | `1px solid #c4c7c5` |
| 圆角 | `8px` |
| 阴影 | 无 |
| 代码字号 | `14px` |
| 代码行高 | `1.5` |
| 编辑器内边距 | 上下 `8px`、右 `12px`、左 `4px` |

### hover 状态

- 默认轮廓保持不变；
- `28px` 深色运行按钮以 `250ms` 淡入；
- 不显示单元格浮动工具条；
- 不改变宽高、内边距或字体；
- 不显示大面积背景色。

### 选中状态

- 使用 `2px #0b57d0` 完整轮廓；
- 不使用左侧 accent 内线；
- 不使用蓝色背景或 focus ring 阴影；
- `160 × 32px` 单元格操作栏显示在框顶部 `-20px`、右侧 `16px`；
- 操作栏使用 `8px` 圆角和 Colab 双层阴影。

### 运行按钮

运行按钮为 `28px` 圆形控件，位于固定 `40px` 左侧区；执行编号独立显示在单元格边框外：

| 状态 | 图标与反馈 |
|---|---|
| idle | 默认隐藏；hover、选中或键盘聚焦时显示深色播放图标 |
| queued | 时钟图标和“排队中”标签 |
| running | 旋转进度环，可点击停止 |
| success | 绿色状态点和执行时间 |
| error | 红色错误图标 |

按钮必须使用可访问名称，不得只使用颜色表达状态。

### 单元格操作

操作栏只在 focus-within 或选中时显示，纯 hover 不显示：

- 上移；
- 下移；
- 复制；
- 折叠；
- 删除。

删除需要撤销能力或确认机制，不允许静默永久删除。

## 7. 输出区域

输出属于对应代码单元格：

- 与编辑器之间使用细分隔线；
- 输出背景为 `output-surface`；
- 最小高度为 `0`，无输出时不占空白区域；
- 长输出可以折叠；
- 输出加载不改变代码编辑器宽度。

### 文本输出

- 使用等宽字体；
- 保留空格和换行；
- 支持复制；
- 超长行横向滚动，不撑破页面。

### DataFrame 与 HTML 表格

- 表头使用浅灰背景；
- 单元格边框低对比；
- 数字右对齐；
- 最大宽度为输出容器宽度；
- 横向滚动仅发生在表格区域；
- 大表格提供折叠或摘要，不一次渲染无限行。

### Matplotlib 与 Seaborn

- 图像保持原始比例；
- 居中展示；
- 最大宽度 `100%`；
- 不对位图进行 CSS 拉伸；
- 深浅主题切换不得使坐标文字不可见。

### Plotly

- 输出容器具有稳定高度或明确 `aspect-ratio`；
- 首次渲染后不得反复改变 Notebook 宽度；
- 响应容器尺寸变化；
- 移动端工具栏不得遮挡图表。

### 错误输出

- 背景使用 `error-soft`；
- 左侧 `3px` error 竖线；
- 错误标题和 traceback 分层；
- 支持复制完整错误；
- 不隐藏 Python traceback。

## 8. 添加与折叠

两个单元格之间 hover 或键盘定位时显示插入线：

- 添加代码；
- 添加文本。

插入控件不得常驻占用大面积垂直空间。

折叠后显示：

- 单元格类型；
- 首行摘要；
- 最近执行状态；
- 展开按钮。

Markdown 标题单元格可折叠其所属内容区段，但首期可以只实现单元格级折叠。

## 9. 菜单与命令面板

- 使用 JupyterLite 官方命令和关闭行为；
- `Escape` 关闭；
- 点击遮罩或外部关闭；
- 打开新菜单时关闭旧菜单；
- 浅色表面、`8px` 圆角、`shadow-menu`；
- 菜单项最小高度 `40px`；
- 禁止同时出现 Jupyter 深色命令面板和 MUI 菜单。

外层应用不得手工修改 `lm-mod-hidden`。

## 10. 主题同步

React 的主题偏好通过 Runtime Bridge 发送：

```text
theme:set { theme: "course-light" }
```

JupyterLite 主题扩展应用对应主题并返回：

```text
theme:changed { theme: "course-light" }
```

首期只发布浅色主题。深色主题必须单独通过输出和图表 QA。

## 11. 响应式

- `>= 1024px`：编号列从左侧 `4px` 开始，内容框从左侧 `44px` 开始，右侧间距 `12px`；
- `768–1023px`：编号列仍为 `40px`，右侧间距 `10px`；
- `< 768px`：编号列从左侧 `2px` 开始，内容框从左侧 `42px` 开始，右侧间距 `8px`；
- 运行区始终为 `40px`，代码字号保持不低于 `14px`；
- 工具栏横向滚动，单元格主体不产生页面级横向滚动；
- 长中文标题允许换行，不与操作按钮重叠。

## 12. 禁止模式

- 外层 Tailwind 覆盖 Notebook；
- 每个 Markdown 单元格绘制 Card；
- 黑底 Markdown 源码误当阅读态；
- hover 改变单元格尺寸；
- 对 CodeMirror 使用脆弱 DOM 选择器；
- 用脚本轮询并重复添加运行按钮；
- 为了模仿 Colab 隐藏关键 Jupyter 功能；
- 运行状态与真实内核状态脱节。
