# 交互与动效规范

## 1. 原则

- 动效解释状态变化，不装饰静态内容；
- 操作反馈靠近用户动作发生的位置；
- 不让动效改变稳定布局尺寸；
- Notebook 编辑和执行优先于品牌表现；
- 所有动效都有减少动画替代方案。

## 2. 时间与缓动

| 类型 | 时长 |
|---|---:|
| hover 与按压 | 120ms |
| 菜单与 Tooltip | 120–180ms |
| Drawer 与辅助面板 | 180–260ms |
| 页面首次进入 | 260ms |

统一缓动：`cubic-bezier(0.2, 0, 0, 1)`。

## 3. React Bits 使用清单

### FadeContent

使用：

- 工作台首次就绪；
- Notebook 加载遮罩退出；
- 空状态切换为实际内容。

限制：

- 不用于每次滚动；
- 不作用于 Notebook 单元格；
- 同一页面进入只播放一次。

### CountUp

使用：

- 总学习进度；
- 完成章节数；
- 数据预览行数。

限制：

- 只在值发生有意义变化时播放；
- 不用于执行时间的持续刷新；
- 减少动画时直接显示最终值。

### ClickSpark

使用：

- 用户点击“运行全部”且命令成功提交；
- 用户完成整个模块。

限制：

- Spark 不超过按钮外 `24px`；
- 不覆盖文字；
- 不代表执行成功，只代表操作已提交；
- 执行结果仍由真实状态显示。

### SpotlightCard

仅用于：

- 首次进入尚未选择章节的欢迎区域；
- 综合项目入口。

不用于课程树和普通章节。

### Stepper

用于首次环境准备：

1. 加载运行时；
2. 准备 Python；
3. 加载课程依赖；
4. 运行时就绪。

Stepper 必须反映真实阶段，不使用假进度。

## 4. 导航交互

- 点击章节立即更新选中状态和 URL；
- Notebook 未保存时仍允许切换，因为工作副本自动保存在 IndexedDB；
- 若保存失败，切换前显示非阻塞提示；
- 返回最近章节时恢复课程树展开状态；
- 搜索结果保持模块上下文。

## 5. 菜单与弹层

- 同一时刻只允许一个顶级菜单；
- 打开 Dialog 时关闭 Menu；
- `Escape` 按以下顺序关闭：Menu -> Dialog -> Drawer；
- 焦点返回触发弹层的控件；
- 点击外部关闭 Menu，但危险确认 Dialog 不允许点击外部关闭。

## 6. 运行交互

### 首次运行

```text
点击运行
-> 显示环境准备 Stepper
-> Runtime Bridge ready
-> 执行单元格
-> 显示真实执行状态
```

不得先显示“已连接”再后台加载内核。

### 执行中

- 运行按钮变为停止按钮；
- 当前单元格显示运行中状态；
- 其他单元格可进入排队状态；
- 页面不会自动跳到顶部；
- 用户可以滚动和阅读其他内容。

### 执行完成

- 成功显示状态点和执行时间；
- 错误显示摘要和完整 traceback；
- 不弹出遮挡 Notebook 的全局成功 Dialog。

## 7. 保存交互

- 编辑后状态变为“有未保存更改”；
- 自动保存时显示“正在保存”；
- 保存成功回到“已保存”；
- 保存失败显示 Snackbar，并保留下载入口；
- 用户主动下载不改变保存状态。

## 8. 恢复与清除

恢复当前 Notebook：

- 使用 MUI Dialog；
- 显示文件名；
- 明确说明会替换浏览器工作副本；
- 提供取消和恢复；
- 恢复后重新打开 Notebook。

清除全部学习数据：

- 作为设置中的危险操作；
- 二次确认；
- 列出会被清除的数据；
- 不删除磁盘中的课程源文件。

## 9. 减少动画

当 `prefers-reduced-motion: reduce` 或用户设置开启时：

- 禁用 ClickSpark；
- CountUp 直接显示最终值；
- Drawer 保留短淡入，不使用位移；
- Stepper 只更新文本和进度；
- 禁用持续旋转之外的装饰动画；
- 必要的加载 spinner 可以保留低频旋转。
