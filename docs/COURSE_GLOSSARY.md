# 课程术语与命名规范

- **版本**：V1.1
- **日期**：2026-08-02
- **适用范围**：109 个连续教学章节 Notebook、8 个独立模块大作业章节、规划中的时间与日期专题、课程文档和评估材料

## 1. 使用原则

课程中的同一个概念只保留一个推荐中文名称。首次出现时给出英文/API 原名，后续使用统一中文名称。代码中的 API 名称不翻译，但 Markdown 解释必须说明其含义。

## 2. 核心术语

| 推荐术语 | 英文/API | 说明 | 避免写法 |
|---|---|---|---|
| 对象 | object | Python 中可被变量引用的值 | 数据、东西 |
| 变量 | variable | 指向对象的名称 | 容器（除非确实强调容器） |
| 参数 | parameter | 函数定义中的输入名称 | 参数/变量混用 |
| 实参 | argument | 调用函数时传入的具体值 | 参数值（可在说明中使用） |
| 返回值 | return value | 函数调用产生的结果 | 输出（输出可指打印结果） |
| 属性 | attribute | 通过点号访问的数据或描述信息 | 字段（对象属性和表格字段要区分） |
| 方法 | method | 绑定在对象上的可调用操作 | 函数（需区分对象方法与独立函数） |
| 函数 | function | 可被调用的代码单元 | 方法（除非确实绑定对象） |
| 序列 | sequence | 有顺序、可按位置访问的数据结构 | 列表（列表只是序列的一种） |
| 数组 | array | 通常指 NumPy 多维数值结构 | 列表（两者性质不同） |
| 表格 | table | 面向行列记录的结构化数据 | 数据框（首次应说明 DataFrame） |
| 数据框 | DataFrame | Pandas 的二维带标签表格 | 表格（可作为通俗解释） |
| 系列 | Series | Pandas 的一维带标签数据 | 一列（Series 不只是一列） |
| 样本 | sample/observation | 数据中的一条观测记录 | 数据点（除非是图形语境） |
| 特征 | feature | 用于描述样本的输入变量 | 自变量（统计语境可补充） |
| 目标 | target | 需要预测或解释的变量 | 标签（分类任务中可同时是标签） |
| 标签 | label | 样本所属的类别或监督信号 | 目标（回归目标不一定叫标签） |
| 缺失值 | missing value | 没有记录或不可用的值 | 空值（必须说明具体表示） |
| 异常值 | outlier | 与总体模式明显不同的观测 | 错误值（两者不等价） |
| 训练集 | training set | 用于拟合模型的数据 | 学习集 |
| 验证集 | validation set | 用于模型选择/调参的数据 | 测试集 |
| 测试集 | test set | 用于最终泛化评估的数据 | 验证集 |
| 基线模型 | baseline model | 用于比较的简单参考模型 | 初始模型（可在解释中补充） |
| 数据泄漏 | data leakage | 训练过程意外使用了不应可见的信息 | 信息泄露（首次可并列） |
| 日期 | `date` | 只有年月日的日期对象 | 时间（日期不一定包含时分秒） |
| 时间 | `time` | 一天中的时、分、秒和微秒 | 日期（两者对象不同） |
| 日期时间 | `datetime` | 同时包含日期和时间的对象 | 字符串时间 |
| 时间间隔 | `timedelta` / duration | 两个时间点之间的长度 | 时间戳（时间戳是数值表示） |
| 时间戳 | timestamp | 通常表示自 Unix 纪元以来的秒数 | 日期字符串 |
| 时区 | time zone | 用于解释本地时间与 UTC 偏移的规则 | 地区名称（地区不一定等于时区） |
| UTC | Coordinated Universal Time | 跨地区比较时间的基准时间 | 北京时间（北京时间是本地时区） |
| naive datetime | naive datetime | 不携带时区信息的日期时间 | UTC 时间（没有时区信息不能直接视为 UTC） |
| 时区感知日期时间 | timezone-aware datetime | 明确携带时区信息的日期时间 | naive datetime |
| 重采样 | resampling | 按新的时间粒度聚合或转换序列 | 排序（排序不改变时间粒度） |
| 滚动窗口 | rolling window | 按连续时间窗口计算统计量 | 分组聚合（窗口有顺序和跨度） |
| 时间泄漏 | temporal leakage / time leakage | 训练时使用了预测时点之后才会知道的信息 | 普通数据泄漏（时间泄漏是其时间顺序场景） |

## 3. 代码命名规范

- 数据框使用带来源或用途的名称，如 `iris_df`、`sales_df`；
- 特征和目标使用 `X`、`y`，在教学 Markdown 中解释含义；
- 训练/测试对象使用 `X_train`、`X_test`、`y_train`、`y_test`；
- 图表对象使用 `fig`、`ax`，多图时使用有意义的后缀；
- 不在同一章节中让 `data`、`result` 指代多个不同对象；
- 代码中的英文 API 保持官方写法，中文只用于注释和解释；
- 输出标签使用中文，标签后保留冒号和单位；
- 方法示例中的变量应在当前 Cell 或紧邻的前置 Cell 明确创建；时间示例还要明确日期格式和时区。

## 4. 教学文字风格

- 先说问题，再说 API；
- 先给最小示例，再补参数和边界；
- 结果解释使用“观察到—说明—限制—下一步”的顺序；
- 避免把“运行成功”写成“模型正确”；
- 对统计和机器学习结论使用谨慎表述，如“在当前数据上表现为”，不写成普遍规律。

## 5. 术语变更流程

新增或修改术语时，先更新本文件，再同步受影响的 Notebook、课程方案、评分量规和质量报告。旧称若必须保留，应标记为“历史称呼”，不得在新 Cell 标题中继续使用。
